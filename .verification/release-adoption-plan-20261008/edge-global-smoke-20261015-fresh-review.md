[Docker documenta](https://docs.docker.com/reference/cli/docker/inspect/) que `--format` evalúa la plantilla por objeto; sobre el contenedor fijado, `.Id` conserva el éxito/fallo de inspección sin producir el JSON completo, y ambos comandos descartan stdout/stderr. La ejecución usa Bash desde stdin, no modifica el script ni la configuración; sus efectos previstos son solicitudes HTTPS públicas y las tres sondas HTTP desde el contenedor existente. **Límites comprobados:** el cambio reduce la materialización de metadatos de `docker inspect`, pero esta ejecución ya no tiene los bytes literales del script canónico; debe nombrarse como smoke canónico con override de una línea. Una baseline previa no prueba la salud posterior al corte, y este smoke no sustituye guards de topología/red ni el preflight Caddy. El canónico acepta cualquier respuesta distinta de 200 en `check_not_served`, incluso un código de fallo de red `000`; esa limitación preexistente no cambia con el launcher. La captura de stdout de Bash se limita a 4096 bytes **después** de que termine el hijo; se mantiene en RAM y no se exporta en bruto. No se ejecutó SSH, Docker ni HTTP durante esta revisión.
